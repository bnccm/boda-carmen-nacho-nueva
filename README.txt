# Invitación de boda · Carmen y Nacho

Prueba HTML para GitHub Pages.

## Publicación
1. Descomprime este ZIP.
2. Sube `index.html` y la carpeta `assets` a la raíz del repositorio.
3. En GitHub, abre Settings → Pages y selecciona la rama principal y `/ (root)`.

La portada usa una acuarela sin texto; las secciones alternan una guirnalda de olivo difuminada a izquierda y derecha.

Antes de publicar, confirma los horarios, el enlace RSVP y si deseas mostrar públicamente los datos bancarios.
